# Data

**Source:** [Brazilian E-Commerce Public Dataset by Olist](https://www.kaggle.com/datasets/olistbr/brazilian-ecommerce), published on Kaggle by Olist.
**License:** CC BY-NC-SA 4.0 (free for non-commercial use with attribution).

| File | Rows | Description |
| --- | --- | --- |
| olist_orders_dataset.csv | 99,441 | One row per order: status and purchase, delivery and estimated dates |
| olist_customers_dataset.csv | 99,441 | Customer record per order; `customer_unique_id` identifies the person |
| olist_order_items_dataset.csv | 112,650 | One row per item: product, seller, price, freight |
| olist_order_payments_dataset.csv | 103,886 | Payment type, instalments, value |
| olist_order_reviews_dataset.csv | 99,224 | Review score (1-5) per order |
| olist_products_dataset.csv | 32,951 | Product category and dimensions |
| olist_sellers_dataset.csv | 3,095 | Seller location |
| product_category_name_translation.csv | 71 | Portuguese to English category names |

The geolocation table (about 61 MB) is not used in this analysis and is not included. Download it from Kaggle if needed.
